# Предзащита 2: демонстрация рабочего прототипа

Цель выступления — показать настоящую ключевую функцию, а не всю инвестиционную презентацию. Ориентир 4–5 минут; фактическое время генерации зависит от компьютера.

## Подготовка

1. По README установить зависимости API, FASHN, подходящий PyTorch и веса. Запустить приложение локально. Перед эфиром выполнить одну настоящую примерку, чтобы скачать вспомогательные веса и прогреть модель.
2. Открыть `http://127.0.0.1:8080/demo`. В настройках выбрать **FASHN VTON 1.5**, а не «Черновик интеграции».
3. Подготовить `app/static/references/person.jpg` и `garment.jpg`; личные фотографии для публичного разбора использовать только с согласия изображённых людей. Демо-материалы проекта не выдавать за фотографии клиентов.
4. Проверить ссылку публичного GitHub в приватном окне без авторизации. Подготовить README и `docs/evidence/real-tryon.json` после успешной проверки.

## Рассказ и показ

**0:00–0:30. Проблема.** Покупателю трудно оценить образ по фотографии модели магазина. В этом прототипе проверяем техническую возможность перенести конкретную вещь на фото покупателя. Размер не определяем.

**0:30–1:00. Гипотеза.** Два исходных фото должны привести к новой картинке через локальную модель и наш интерфейс. Доходы, подписки, сервер за 1,1 млн ₽ и облачная инфраструктура для выполнения задания не нужны.

**1:00–3:00. Живой сценарий.** Загрузить фото человека и вещи, выбрать категорию «Верх» и тип «На белом фоне», проверить FASHN в настройках, нажать «Примерить». Показать состояние очереди/прогресса. Дождаться нового результата. Сравнить одежду и лицо с исходными фотографиями.

Если генерация не успевает в отведённое время, показать ранее полученный проверочный результат и его отчёт, явно назвав его записью предыдущего запуска. Это резерв выступления, а не замена демонстрации работающего прототипа.

**Пока идёт обработка. Работа с агентом.** Объяснить постановку задачи, что было проверено человеком, как отличили настоящий результат от имитации и какие ошибки нашли.

**Финал. Ограничения и следующий шаг.** Назвать фактическое время на текущем устройстве. Пять секунд остаются целью оптимизации. Следующая проверка — серия фото с принтами и сложными позами; влияние на покупки потребует отдельного эксперимента.
