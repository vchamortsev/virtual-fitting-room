# Работа с ИИ-агентом

Продукт: виртуальная примерочная для небольшого fashion-магазина. Автор по исходной презентации: Владимир Чаморцев, один участник. Совместная работа команды не подтверждается представленными материалами; если состав команды изменился, его нужно уточнить перед сдачей.

## Что сделано с Codex в этой проверке

1. Пользователь передал текст домашнего задания и попросил проверить соответствие, исправив недочёты.
2. Агент изучил код, README, Git и инструкции запуска; отделил рабочую генерацию от `mock` и от заранее сохранённых примеров.
3. Выполнены существующие автоматические тесты. Проверка настоящей генерации выполняется отдельно через API приложения скриптом `scripts/verify_real_tryon.py`.
4. README дополнен одной ключевой гипотезой, критериями проверки, сценарием и границами прототипа. Добавлены материалы к демонстрации и правила подготовки публичного репозитория.
5. Пользователь может просмотреть изменения, повторить запуск, оценить новое изображение и выбрать дальнейшие доработки. Реакция реальных магазинов и совместная оценка команды не выдумываются.

## Как поставить следующую задачу агенту

«Проверь локальный сценарий: загрузить фото человека и товара, явно выбрать FASHN, дождаться нового результата. Не подменяй его готовым примером или mock. Сохрани параметры и время. Сообщи, какие детали товара и лица изменились. Не загружай личные фотографии в сторонние сервисы и не публикуй секреты».

Для отчёта достаточно описания задачи, изменений и проверки результата. Полную переписку публиковать необязательно: она может содержать личные данные. История первоначальной разработки до этой проверки отдельно не восстанавливалась.
