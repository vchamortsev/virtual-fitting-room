## Источники

- Littledata: https://www.littledata.io/benchmarks/fashion — 74 fashion-магазина Shopify, медианная конверсия 1% визитов, данные за август–октябрь 2026. Доля визитов без покупки около 99% не означает, что все они потеряны из-за отсутствия примерки.
- Faslet / Garcia: https://faslet.me/cases/business-case-garcia/ — по сообщению поставщика, относительный рост конверсии 7,06% при доступе к виртуальной примерке. Обе группы уже пользовались size-me. Примерка на похожем теле отличается от нашего переноса одежды на собственное фото.

Сценарий: 10 000 × 1% = 100 заказов; 100 × 1,0706 = 107,06 заказа. Это иллюстрация по чужому кейсу, не прогноз. Окупаемость тарифа для магазина при условном вкладе 1 800 ₽/заказ: 9 900 / 1 800 = 5,5, значит не менее 6 дополнительных заказов без прочих дополнительных расходов и при соблюдении лимита примерок.
