# Публикация для сдачи

Репозиторий проекта: https://github.com/vchamortsev/virtual-fitting-room . Для сдачи используется именно эта ссылка, а не ссылка на профиль.

1. На https://github.com/new создать репозиторий `virtual-fitting-room` с видимостью **Public**. Описание: «Локальный прототип виртуальной примерочной: FastAPI, FASHN, проверка переноса одежды по двум фото». Если код будет загружаться целиком, не добавлять автоматически README и лицензию: они уже есть в проекте.
2. Распаковать `virtual-fitting-room_GitHub.zip` из папки `output` рабочего пространства. Архив подготовлен из файлов, выбранных Git, без `.git`, `.env`, весов, пользовательских данных и временных заданий.
3. Через Upload files загрузить **распакованные файлы и папки**, сохранив структуру. В корне GitHub должны быть README.md, app, scripts, tests и requirements.txt. Загрузка одного ZIP вместо кодовой базы не выполняет требование задания.
4. Проверить проект в приватном окне без входа: видны README, исходники и инструкции запуска. Проверить, что `docs/evidence/real-tryon.png` открывается.
5. Скопировать реальную ссылку созданного репозитория на платформу и в лист «Предзащита 2». Не использовать предполагаемый адрес до создания и проверки репозитория.

При изменениях кода повторно выполнить тесты и `python scripts/prepare_submission.py`. Поиск секретов проверяет типичные шаблоны токенов в текущих файлах, а не гарантирует отсутствие любых конфиденциальных данных. Личные фотографии и данные клиентов перед публикацией проверяются отдельно.

Публичный репозиторий уже создан пользователем. Инструкция выше остаётся способом воспроизвести публикацию или загрузить обновления. Подключение GitHub подтверждено; повторное подключение не требуется.
